## [v0.1.0] - 2026-10-10 ([`4865e98`](https://github.com/grokify/datacatalog/commit/4865e98))

### Highlights

- A dependency-free Go model for describing which entities and fields an application stores and how each is classified, with validation and a query-guard predicate

### Added

- Catalog, entity and field model: visibility (`public` or `internal`), independent `pii` and `secret` tags, erasure strategy, export flag, subject key, privacy scope, hold applicability, versioning and retention note ([`cacd103`](https://github.com/grokify/datacatalog/commit/cacd103))
- `Validate` reports every problem at once, with rule identifiers: explicit visibility, `secret` implies `internal`, subject key required and known, erasure required for personal data in privacy scope, retain reason required, unique names ([`41993e1`](https://github.com/grokify/datacatalog/commit/41993e1))
- Audience filtering (`VisibleTo`, `VisibleFields`) and default-deny query predicates (`AllowedInQuery`) that always block internal and secret fields and block personal data unless allowed ([`48c2845`](https://github.com/grokify/datacatalog/commit/48c2845))
- JSON load and save with stable ordering, `Merge` that reports conflicting entity definitions, and a Markdown renderer for documentation ([`7e9e63d`](https://github.com/grokify/datacatalog/commit/7e9e63d))
- JSON Schema generated from the Go types and embedded, with a test that fails when the committed schema drifts ([`2aa1cb3`](https://github.com/grokify/datacatalog/commit/2aa1cb3))
- Guides: model and validation reference, and erasure strategies ([`4865e98`](https://github.com/grokify/datacatalog/commit/4865e98))
